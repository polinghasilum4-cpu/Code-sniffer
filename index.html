About

Tentang Snippet Vault

💎 Snippet Vault

Snippet Vault adalah aplikasi web ringan untuk menyimpan, mengelola, dan membagikan potongan kode. Semua data disimpan di browser lo menggunakan localStorage.

✨ Fitur

  • 📝 Simpan snippet dengan syntax highlighting
  • 🔍 Cari cepat berdasarkan judul, tag, atau isi kode
  • 🏷️ Filter berdasarkan bahasa pemrograman
  • 📋 Copy kode sekali klik
  • ⭐ Tandai snippet sebagai favorit
  • 📱 Responsive, smooth di HP Android

🛠️ Tech Stack

HTML5 · CSS3 · Vanilla JavaScript. Zero dependencies.
